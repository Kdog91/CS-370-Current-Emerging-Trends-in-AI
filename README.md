## Assignments

### Assignment 2 - Identifying Handwritten Digits
**File:** `Simmons_Nikki_Assignment2.html`

Built and trained a neural network using the MNIST handwritten digits dataset 
in a Jupyter Notebook environment (Codio). Experimented with modifying the 
number of training epochs to observe the effect on training, validation, and 
test accuracy. Analyzed the role of the optimizer and learning rate in model 
convergence.

**Tools & Libraries:** Python, Keras, NumPy, Jupyter Notebook
